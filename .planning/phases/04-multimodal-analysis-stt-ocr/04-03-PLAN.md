# Phase 4 Plan 03: Multimodal Pipeline Integration & Evidence Attribution

## Objective

- **What:** Integrate STT transcription, bounded keyframe sampling, and on-screen OCR extraction into SAVEit's core item analysis pipeline; ground generated takeaways and resources to verifiable transcript and OCR evidence with timestamps; and preserve honest processing statuses.
- **Why:** Delivers on MM-01, MM-02, MM-03, and MM-04 by connecting speech and visual video frames directly to structured personal knowledge, allowing users to verify where each takeaway, terminal command, and code snippet came from.
- **Output:** `evidenceGrounding.ts`, `multimodalService.ts`, updated `Item.ts` schema, updated `itemController.ts`, and end-to-end integration tests `multimodalIntegration.test.ts`.
