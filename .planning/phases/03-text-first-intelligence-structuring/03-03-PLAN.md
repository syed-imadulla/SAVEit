# Phase 3 Plan 03: SSRF-Guarded Link Verification, Schema Updates & API Pipeline Integration

## Objective

- **What:** Implement candidate link verification with SSRF protection, update the Mongoose `Item` schema to persist structured knowledge, integrate structuring into `POST /api/items`, and provide the `POST /api/items/:id/analyze` endpoint.
- **Why:** Extracted URLs may be broken or internal/private IP exploits. Verifying candidate links and persisting clean structured takeaways completes the Phase 3 value proposition.
- **Output:** `linkVerifier.ts`, updated `Item.ts`, updated `itemController.ts` & `itemRoutes.ts`, and end-to-end integration tests.
