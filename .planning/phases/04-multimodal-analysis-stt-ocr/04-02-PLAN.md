# Phase 4 Plan 02: Keyframe Sampling & On-Screen OCR Engine

## Objective

- **What:** Build a bounded, safe keyframe sampling engine using FFmpeg, create a modular OCR provider abstraction, and build an on-screen text/code/command extractor that attributes evidence to exact frame timestamps.
- **Why:** Short-form coding and tutorial videos frequently convey core insights (terminal commands, configuration flags, code snippets, package names) visually on screen rather than speaking them. Sampling frames and running OCR extracts this visual evidence without storing complete video binaries.
- **Output:** `keyframeSampler.ts`, `ocrProvider.ts`, `ocrExtractor.ts`, updated `types.ts`, and comprehensive test suites (`keyframeSampler.test.ts`, `ocrExtractor.test.ts`).
