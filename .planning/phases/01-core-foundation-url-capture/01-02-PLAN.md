# Phase 1 Plan 02: Backend API & Persistent Storage Layer

## Objective

- **What:** Implement the Node.js/Express backend service in `server/` with TypeScript, MongoDB connection via Mongoose, strict URL/SSRF validation, and item CRUD endpoints.
- **Why:** Delivers the core data persistence engine and validation contract needed to reliably accept and store shared video links before downstream AI processing begins.
- **Output:** Fully functional, typed Express API with Mongoose `Item` model, validation engine, and automated tests.
