# Phase 2 Plan 02: Modular Retrieval Interface & YouTube Adapter

## Objective

- **What:** Define the core `RetrievalAdapter` interface, structured `EvidenceReport` schema, and implement `YouTubeAdapter` with layered zero-auth metadata and transcript extraction.
- **Why:** Provide a clean, testable contract for extracting evidence from YouTube Shorts while respecting platform boundaries and supporting graceful degradation.
- **Output:** Typed retrieval interfaces, production-ready `YouTubeAdapter`, and automated test suite.
