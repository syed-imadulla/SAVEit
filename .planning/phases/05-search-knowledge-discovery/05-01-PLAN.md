# Phase 5 Plan 01: Full-Text Search & Multi-Criteria Filtering Backend

## Objective

- **What:** Implement high-performance server-side search and filtering for saved video items in MongoDB, supporting full-text queries, partial substring matches, tag filters, sorting, and tag discovery.
- **Why:** Satisfies requirement SCH-01 by enabling users to locate saved knowledge even when they only remember a partial tool name, concept, or takeaway.
- **Output:** Updated `Item.ts` with text and compound indexes, enhanced `GET /api/items`, new `GET /api/tags` endpoint, and automated test suite `search.test.ts`.
