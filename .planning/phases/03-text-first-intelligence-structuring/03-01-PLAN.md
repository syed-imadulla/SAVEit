# Phase 3 Plan 01: Text Preprocessing, Structuring Contracts & LLM Providers

## Objective

- **What:** Build the foundational text preprocessing pipeline, type contracts, and LLM provider abstractions (Mock & Gemini) for text-first video knowledge structuring.
- **Why:** Short-form video transcripts contain timestamps, noise tags ([Music], [Applause]), and fragmented sentences. Before invoking AI models, transcripts must be cleaned, bounded, and formatted. The LLM provider abstraction ensures robust offline testing and pluggable AI providers.
- **Output:** `types.ts`, `textCleaner.ts`, `llmProvider.ts`, and comprehensive unit tests.
