# Phase 2 Plan 03: Instagram Adapter, Registry & Backend API Pipeline Integration

## Objective

- **What:** Implement `InstagramAdapter` with public metadata probing and honest login-wall detection, build the centralized `AdapterRegistry`, and integrate retrieval into the backend `POST /api/items` flow.
- **Why:** Delivers end-to-end evidence retrieval where capturing a URL automatically retrieves real metadata/transcripts and updates item status honestly across both Instagram and YouTube.
- **Output:** Instagram adapter, adapter registry, backend integration, and end-to-end test suite.

## Verification Criteria

1. Submitting a YouTube Short via `POST /api/items` populates title, author, and thumbnail, updating status from `queued` to `metadata_only` or `partially_analyzed`.
2. Submitting an Instagram Reel produces honest metadata or `metadata_only`/`unsupported_inaccessible` with platform restriction diagnostics.
3. Original source URL and capture date remain intact.
4. All automated unit and integration tests pass cleanly.
